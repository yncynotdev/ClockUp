# ClockUp v1.0.0-rc — Release Candidate 1

**Beta Release** · Release Candidate

## Overview

ClockUp reaches its first release candidate, marking an important milestone toward version 1.0.0. This release focuses on correcting attendance status counts and refining the production deployment workflow.

Although this release introduces few user-facing changes, it represents a step toward validating ClockUp's readiness for its first stable release.

## 🛠️ Fixes & Improvements

- **Attendance Status Counts:** Fixed an issue affecting the displayed attendance status counts, improving the accuracy of attendance summaries.
- **Production Deployment Workflow:** Updated the CI/CD workflow to promote changes from `master` to `production`, aligning the deployment process with the release workflow.
- **Development OTP Logging:** Added console output for one-time passwords (OTPs) in the development environment to simplify authentication testing.

## 📌 What This Release Means

The `v1.0.0-rc` milestone marks ClockUp's transition from ongoing beta development toward release validation. The focus now shifts to testing core attendance workflows, verifying deployment stability, and addressing issues discovered before the stable release.

## ⚠️ Release Candidate Status

This is a **release candidate**, not the final stable release. While ClockUp is approaching version 1.0.0, further fixes or changes may still be necessary before the stable release is published.

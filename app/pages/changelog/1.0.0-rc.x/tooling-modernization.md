# ClockUp v1.0.0-rc.2 — Tooling Modernization

**Pre-release** · Release Candidate

## Overview

This release focuses on development tooling and continuous integration as ClockUp continues toward version 1.0.0. The project migrates to Vite+ and fixes a client CI workflow issue related to frozen-lockfile configuration.

While this update introduces no major user-facing features, it improves the project's development and build workflow during release-candidate testing.

## 🛠️ Tooling Improvements

- **Vite+ Migration:** Migrated the project to Vite+, modernizing the development tooling setup.
- **Client CI Fix:** Removed the problematic frozen-lockfile setting from the client workflow to resolve a CI configuration issue.

## 📌 What This Release Means

This update keeps the focus on the engineering foundation behind ClockUp. Reliable tooling and continuous integration help support consistent builds, smoother maintenance, and continued validation before the stable release.

## ⚠️ Pre-release Status

ClockUp remains in the release-candidate phase. Further fixes and refinements may be introduced as testing continues ahead of version 1.0.0.

# ClockUp — Introducing ClockUp

**Beta Release** · Internal

## Overview

This release marks an important step in the evolution of the attendance management system, introducing the ClockUp identity alongside improvements to navigation, accessibility, documentation, and user transparency.

The application interface has been updated to reflect the new name, while Filipino language support makes the system and its documentation more accessible to local users.

This release also introduces an admin command palette, improvements to the support page, and a camera consent notice for attendance capture.

## ✨ Introducing ClockUp

The application interface has been updated from PETER to ClockUp.

- Updated application branding and interface references.
- Aligned the client interface with the ClockUp identity.
- Continued refining the product's presentation and user experience.

This marks the transition to the ClockUp name across the application interface.

## ⌘ Admin Command Palette

A command palette has been introduced to improve navigation within the admin interface.

- Added a command palette for administrative navigation.
- Made navigation options accessible through a centralized interface.
- Provided a faster way to locate and access supported admin functions.

The command palette establishes a more efficient navigation experience as the administrative interface continues to grow.

## 🇵🇭 Filipino Language Support

ClockUp now supports Filipino/Tagalog through internationalization using `@nuxtjs/i18n`.

- Added Filipino language support to the application.
- Introduced translated documentation for the user manual.
- Improved accessibility for Filipino-speaking users.
- Established a foundation for maintaining localized application content.

This makes ClockUp more approachable for local users while preparing the system for additional language support in the future.

## 📷 Attendance Camera Consent

A camera consent notice has been added to the attendance capture workflow.

- Introduced a notice informing users about camera use.
- Improved transparency around image capture during attendance.
- Made camera-related consent part of the user experience.

This helps users better understand when camera functionality is involved in the attendance process.

## 🛠️ Support & Infrastructure Improvements

Additional refinements were included in this release.

- Improved the support page.
- Fixed issues affecting the Pages deployment workflow.
- Refined the application experience alongside the branding update.

These changes help maintain a more consistent user experience and reliable deployment process.

## 📌 What This Release Means

This release establishes ClockUp's updated product identity while improving how users interact with the system.

The command palette streamlines administrative navigation, Filipino language support improves accessibility, and the camera consent notice provides greater transparency during attendance capture.

Together, these changes move ClockUp toward a more approachable, locally accessible, and user-conscious attendance management experience.

## ⚠️ Beta Status

ClockUp remains in beta and is under active development. Features, behavior, architecture, and implementation may continue to change before the eventual `1.0.0` stable release.
